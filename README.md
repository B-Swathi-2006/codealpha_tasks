
# CodeAlpha AI Internship Tasks

This repository contains my projects completed during the CodeAlpha AI Internship.

## Projects

### 1. FAQ Chatbot
A Python-based chatbot that answers frequently asked questions using NLP and text similarity.

### 2. Language Translator
A web-based language translation application built using Python and Flask. Supports English, Hindi, Kannada, Tamil, and Telugu.

### 3. Object Detection and Tracking
A real-time object detection and tracking application using YOLOv8 and OpenCV. It detects objects, tracks them with IDs, counts detected objects, and stores detection history in a CSV file.
